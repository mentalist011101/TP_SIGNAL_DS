# Textes à lire pendant la session

> À imprimer en gros caractères. Lire lentement, avec 1 s de silence avant et après chaque phrase.

## Phrases d'émotion — P1 à P3

Ces phrases ont un **sens neutre**, comme dans CREMA-D : c'est la **voix** qui porte l'émotion,
pas les mots. On lit chacune dans les 6 émotions : neutre, joie, tristesse, colère, peur, dégoût.

| Code | Phrase |
| --- | --- |
| P1 | Le rendez-vous est fixé à jeudi après-midi. |
| P2 | Il a posé le carton sur la table de la cuisine. |
| P3 | Nous prendrons le bus de huit heures demain matin. |

## Enrôlement du locuteur — E1 à E5

Voix normale. Ces phrases servent à **enregistrer** la voix dans l'application (EF-11).

| Code | Phrase |
| --- | --- |
| E1 | Bonjour, je participe à l'enregistrement du projet EchoLens aujourd'hui. |
| E2 | La saison des pluies commence souvent au mois de mars dans cette région. |
| E3 | Pour aller au marché, il faut traverser le pont et tourner à gauche. |
| E4 | Mon numéro préféré est le sept, et ma couleur préférée est le vert. |
| E5 | Les étudiants ont rendu leur rapport juste avant la fin de la semaine. |

## Test du locuteur — T1 à T5

Voix normale. Ces phrases sont **différentes** de celles de l'enrôlement (P11) : on vérifie que
l'application reconnaît la voix, pas la phrase.

| Code | Phrase |
| --- | --- |
| T1 | Le train venant de Douala est arrivé avec une heure de retard. |
| T2 | Elle a acheté trois mangues, du pain et une bouteille d'eau. |
| T3 | La réunion de ce soir est reportée à la semaine prochaine. |
| T4 | Il faut charger l'ordinateur avant de commencer la présentation. |
| T5 | Nous avons regardé le match ensemble chez un ami du quartier. |

## Clonage de voix — C1 (facultatif)

Voix normale et régulière, environ une minute. **Seulement** si la case 5 du formulaire est
cochée.

> Ce matin, le ciel était gris et l'air sentait la pluie. Au carrefour, les vendeurs installaient
> déjà leurs tables, et les taxis jaunes klaxonnaient pour attirer les passants. J'ai pris le
> temps de boire un café avant de rejoindre la salle de cours. Le professeur nous a rappelé que le
> projet devait être rendu au début du mois de décembre, et qu'il faudrait le présenter devant un
> jury. Nous avons donc partagé le travail : une personne prépare les données, une autre entraîne
> les modèles, une troisième construit l'application, et tout le monde relit le rapport. Le plus
> difficile n'est pas d'écrire le code, mais de pouvoir expliquer chaque choix simplement. Ce soir,
> nous ferons le point sur ce qui reste à faire, puis chacun rentrera chez soi avant la nuit.

## Événements sonores

Un fichier par essai, 3 essais par son (`x1`, `x2`, `x3`), environ 5 s chacun. L'étiquette est
l'identifiant exact de la classe d'ESC-50.

| Étiquette | Comment le produire |
| --- | --- |
| `door_wood_knock` | Frapper 3 à 4 coups sur une porte en bois |
| `door_wood_creaks` | Ouvrir lentement une porte qui grince |
| `footsteps` | Marcher dans la pièce, chaussures aux pieds |
| `clapping` | Applaudir |
| `coughing` | Tousser |
| `laughing` | Rire |
| `keyboard_typing` | Taper un texte au clavier |
| `mouse_click` | Cliquer plusieurs fois avec la souris |
| `pouring_water` | Verser de l'eau dans un verre |
| `can_opening` | Ouvrir une canette |
| `drinking_sipping` | Boire à petites gorgées |
| `clock_alarm` | Faire sonner l'alarme d'un téléphone |
